# Laporan Audit Kualitas & Keamanan Repositori (`absensi_refactored_v6`)

**Apa yang dilakukan repositori ini:** Platform multi-instansi untuk absensi pegawai pemerintah (**HADIR**), manajemen aset (**SIMAPO**), dan arsip digital (**E-Arsip**) di lingkungan BAPPERIDA Sumba Barat beserta instansi mitra. Sistem ini berjalan sebagai Telegram Mini App, Web PWA, dan aplikasi Android (Capacitor APK) menggunakan frontend Vanilla JS ([index.html](file:///D:/Code/absensi_refactored_v6/index.html) + `js/*.js`) serta backend Express + PostgreSQL (`pg`) di dalam satu container Docker Nginx/Node.
**Asumsi beban (load):** 50–300 pegawai lintas instansi (`instansi_id`) dengan lonjakan trafik tajam pada jam masuk (07:30–08:00 WITA) dan jam pulang (16:00–17:00 WITA).
