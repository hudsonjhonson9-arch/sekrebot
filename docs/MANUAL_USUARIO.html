Masuk Aplikasi (Login)

Halaman pertama saat aplikasi dibuka. Gunakan NIP atau ID pegawai untuk masuk.

Layar Login
  1. Tahapan Penggunaan
  2. Buka aplikasi HADIR dari Telegram (Mini App) atau browser.
  3. Pastikan tab Masuk yang terpilih.
  4. Isi kolom NIP / NISN / NIM / ID dengan NIP Anda.
  5. Tekan tombol Masuk Sekarang 🚀.
  6. Pengguna baru: pilih tab Daftar untuk membuat akun terlebih dahulu.

Tab Absen (Halaman Utama)

Layar utama untuk mencatat kehadiran masuk dan pulang berbasis lokasi GPS.

Tab Absen
  1. Tahapan Penggunaan
  2. Buka tab Absen (ikon utama di bawah).
  3. Aktifkan GPS/lokasi pada perangkat dan pastikan berada dalam area kantor.
  4. Periksa status lokasi terdeteksi pada kartu Lokasi Terdeteksi.
  5. Tekan tombol 📍 Kirim Lokasi & Absen.
  6. Cek catatan pada Log Absen Hari Ini; tombol 🔄 untuk memuat ulang.
  7. Jika bekerja di lapangan, isi Keterangan Lokasi Lapangan lalu tekan 🏃 Pulang dari Lapangan.

Tab Keterangan

Mengajukan izin, sakit, atau tugas yang akan diperiksa admin.

Tab Keterangan
  1. Tahapan Penggunaan
  2. Buka tab Keterangan.
  3. Pilih jenis keterangan: 🙏 Izin, 🤒 Sakit, 💼 Tugas, 🎓 Tubel, atau 🏖️ Cuti.
  4. Tentukan rentang tanggal mulai–selesai.
  5. Tulis keterangan/alasan pada kolom yang disediakan.
  6. Lampirkan bukti (foto/dokumen) bila diperlukan.
  7. Tekan 📤 Kirim Keterangan, lalu pantau statusnya di Riwayat Pengajuan Saya.

Tab Rekap

Melihat rekap kehadiran pegawai per rentang tanggal dan mengekspor laporan.

Tab Rekap
  1. Tahapan Penggunaan
  2. Buka tab Rekap.
  3. Pilih rentang tanggal atau tombol cepat: Hari Ini, Minggu Ini, Bulan Ini, dst.
  4. Pilih instansi dan filter bidang/unit kerja (khusus admin).
  5. Tekan Muat untuk menampilkan data kehadiran.
  6. Unduh laporan dengan 📊 Excel Rekap atau 📄 PDF Rekap.

Tab Profil

Data diri, verifikasi wajah, tanda tangan digital, dan riwayat absen pribadi.

Tab Profil
  1. Tahapan Penggunaan
  2. Buka tab Profil.
  3. Perbarui Face Recognition (data wajah) dengan tombol 🔄 Perbarui.
  4. Kelola ✍️ Tanda Tangan Digital untuk rekap PDF.
  5. Unggah 📁 Dokumen Kepegawaian bila diperlukan.
  6. Tinjau Riwayat Absen dan Akumulasi Waktu (hadir, terlambat, disiplin).
  7. Tekan 🚪 Keluar dari Akun ini untuk logout.

Tab Perjalanan Dinas

Membuat dan memantau penugasan/perjalanan dinas pegawai.

Perjalanan Dinas
  1. Tahapan Penggunaan
  2. Buka LAINNYA lalu pilih Perjalanan Dinas.
  3. Tekan BUAT PENUGASAN BARU.
  4. Pilih pegawai dan tentukan titik koordinat tugas (opsional).
  5. Isi pemberi tugas, nomor surat, keterangan, tanggal, dan radius.
  6. Tekan 💾 Simpan Penugasan.
  7. Pantau status pada Monitoring Progres; konfirmasi dengan bukti bila tugas selesai.

Tab Rekap Lembur

Menarik data absen harian untuk menghitung rekap lembur pegawai.

Rekap Lembur
  1. Tahapan Penggunaan
  2. Buka LAINNYA lalu pilih Rekap Lembur.
  3. Pilih rentang tanggal lembur.
  4. Ceklis Sertakan Hari Sabtu bila hari Sabtu termasuk kerja.
  5. Pilih pegawai dan isi Dalam Rangka (perihal lembur).
  6. Tekan 📊 Tarik Data Lembur; rekap tersimpan pada Arsip Rekap Lembur.

Tab Aset (SIMAPO)

Katalog aset daerah untuk melihat, meminjam, dan melaporkan barang.

Katalog Aset
  1. Tahapan Penggunaan
  2. Buka LAINNYA lalu pilih Aset.
  3. Gunakan kolom Cari nama barang atau kode untuk mencari aset.
  4. Pilih tab Katalog untuk daftar barang, atau Pinjam untuk meminjam.
  5. Gunakan tab Lapor untuk melaporkan kerusakan barang.
