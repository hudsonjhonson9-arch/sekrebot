# Migrate Face Photos & Signatures to Google Drive — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Task 1 is blocking; everything else depends on it.

**Goal:** Replace base64 image blobs in PostgreSQL with Google Drive file URLs for face photos and employee signatures, served by a new Express backend that talks to a minimal Google Apps Script, while the existing n8n workflows keep working as a fallback.

**Architecture:** The browser calls a new `SERVER_MEDIA` base URL using a new `mediaPost`/`mediaGet` pair in `js/api.js` (the existing `apiFetch` is left untouched because it hardcodes the n8n bases `SERVER_1`/`SERVER_2` and has 46 call sites). Express validates the session token against `user_list`, converts the `data:` URL to a Buffer, hands it to Apps Script, stores the returned canonical Drive URL in `user_list.face_photo` / `tanda_tangan.signature`, and leaves `face_histogram`, `face_model`, and `face_saved_at` as local JSON. `<img>` consumers route through a new `driveDirectUrl()` helper; the PDF path uses `/api/media/raw/:fileId`.

**Tech Stack:** Node 20+ ESM (`package.json` already declares `"type": "module"`), Express 4, `pg`, `node:test` for tests, Google Apps Script V8 runtime.

## Global Constraints

- **Ground truth is `n8n/export/*.json`.** The production Postgres schema is only observable through the queries inside those workflow exports. Every column name below was extracted from them, not guessed.
- **Schema (do not migrate):** `user_list(id PK, face_photo, face_histogram, face_model, face_saved_at, role, instansi_id, NIP)` and `tanda_tangan(nip PK, signature, saved_at, saved_by, updated_at)`. Source: `Simpan Histogram ke user_list` and `Upsert Signature` nodes.
- **`user_list` primary key is `"id"`, not `"user_id"`.** The n8n write is `UPDATE "user_list" SET ... WHERE "id" = $5`, where `$5` is the request field `user_id`. Do not "fix" this — Express must use `WHERE id = $n`.
- **`face_photo` / `signature` become canonical URLs** of the form `https://drive.google.com/file/d/<FILE_ID>/view`. Legacy values are `data:` URLs and stay readable until migrated.
- **Drive files are public** (`ANYONE_WITH_LINK`, `VIEW`). The biometric-exposure risk is accepted and documented in the spec.
- **`app.js`/`js/` is the only frontend source of truth.** `www/`, `android/app/src/main/assets/public/`, and `dist/` are generated by `scripts/setup-capacitor.js:34` and `vite build`. Never edit them.
- **Never modify `apiFetch` (`js/config.js:356`).** It retries across `[SERVER_1, SERVER_2]` and has 46 call sites. Media calls get their own transport.
- **Existing n8n workflows stay deployed and unmodified until Task 14 passes.** Nothing in Tasks 1–13 stops media traffic from reaching n8n.
- **`MEDIA_BACKEND_ENABLED` gates every media call.** It defaults to `false`. While it is off, the frontend uses the existing n8n endpoints and the old code path stays in the source. Turning the flag on is the *only* step that diverts traffic, and turning it back off is a complete rollback — no data repair, no config undo. The n8n code paths are deleted in Task 15, never earlier.
- **The flag is a build-time constant, so flipping it requires a frontend rebuild and redeploy.** A browser bundle has no access to `process.env`, so `const MEDIA_BACKEND_ENABLED = false` cannot be changed at runtime from the server. Rollback therefore means: change the constant back to `false`, rebuild, redeploy, hard-reload. If instant rollback without a deploy is a hard requirement, the flag has to become runtime-sourced — `window.__MEDIA_CONFIG__` injected by a server endpoint, or `import.meta.env.VITE_MEDIA_BACKEND_ENABLED` baked at build time. Decide before Task 14; the plan as written assumes a redeploy on every flip and that redeploy must stay fast.
- **Rollout is: staging first, then canary, then n8n shutdown.** Task 14 is a gate with explicit pass criteria. Do not run Task 15 until Task 14 is green and has been green for one full week of production traffic.
- **`resetFacePegawai` is duplicated** at `js/admin-face.js:599` and `js/admin.js:2276`. Both must be updated; deleting the duplicate is a separate cleanup task, not this one.
- **Test command is `node --test`** from the repo root. Baseline before starting: 53 passing. Run it after every task.
- **Production Postgres writes are currently restricted to n8n by `AGENTS.md`.** Task 12 reconciles that rule; until then no migration script may touch production.
- Apps Script `doGet`/`doPost` must return real HTTP status codes. The reference implementation at `D:\Code\peta-ekonomi\google-apps-script\Code.gs:26` has a `res(code, body)` helper that silently discards `code` and always returns 200 — do not copy that defect.

```js
export function parseToken(token) {
  if (typeof token !== 'string') return null;
  const parts = token.split('_');
  if (parts.length < 3 || parts[0] !== 'usr') return null;
  const id = Number(parts[1]);
  return Number.isSafeInteger(id) && id > 0 ? id : null;
}

export function bearerToken(req) {
  const raw = req.headers?.authorization || '';
  const [scheme, ...rest] = raw.split(' ');
  const value = rest.join(' ').trim();
  if (!value) return null;
  return scheme.toLowerCase() === 'bearer' ? value : value === raw.trim() ? raw.trim() : null;
}
```

```javascript
const MAX_BYTES = 5 * 1024 * 1024;
const MIME_PREFIX = 'image/';

function jsonOut(code, body) {
  return ContentService
    .createTextOutput(JSON.stringify(body))
    .setMimeType(ContentService.MimeType.JSON)
    .setResponseCode(code);
}

function readParams_(e) {
  if (!e) return {};
  if (e.postData && e.postData.contents) {
    try { return JSON.parse(e.postData.contents); } catch (err) { return {}; }
  }
  return e.parameter || {};
}

function folderId_() {
  const id = PropertiesService.getScriptProperties().getProperty('DRIVE_FOLDER_ID');
  if (!id) throw new Error('DRIVE_FOLDER_ID belum diset di PropertiesService');
  return id;
}

function fileIdFromUrl(url) {
  const m = String(url || '').match(/\/file\/d\/([-\w]+)/);
  return m ? m[1] : null;
}

function canonicalUrl_(fileId) {
  return 'https://drive.google.com/file/d/' + fileId + '/view';
}

function doGet(e) {
  const p = readParams_(e);
  try {
    if (p.action === 'health') {
      return jsonOut(200, { ok: true, folderId: folderId_() });
    }
    return jsonOut(404, { ok: false, message: 'action tidak dikenal' });
  } catch (err) {
    return jsonOut(500, { ok: false, message: String(err && err.message || err) });
  }
}

function doPost(e) {
  const p = readParams_(e);
  if (p.action !== 'mediaUpsert') {
    return jsonOut(400, { ok: false, message: "action wajib 'mediaUpsert'" });
  }
  if (!p.filename || !p.mimeType) {
    return jsonOut(400, { ok: false, message: 'filename dan mimeType wajib diisi' });
  }
  if (MIME_PREFIX.indexOf(p.mimeType) !== 0) {
    return jsonOut(400, { ok: false, message: 'mimeType harus berupa image/*' });
  }
  if (!p.dataBase64) {
    return jsonOut(400, { ok: false, message: 'dataBase64 wajib diisi' });
  }

  let bytes;
  try {
    bytes = Utilities.base64Decode(p.dataBase64);
  } catch (err) {
    return jsonOut(400, { ok: false, message: 'dataBase64 bukan base64 yang valid' });
  }
  if (bytes.length > MAX_BYTES) {
    return jsonOut(413, { ok: false, message: 'ukuran file melebihi 5 MB' });
  }

  try {
    const blob = Utilities.newBlob(bytes, p.mimeType, p.filename);
    // Upload pertama membuat file baru (blob sudah berisi isinya). Upload
    // berikutnya menimpa file yang sama lewat fileId, bukan membuat duplikat.
    const file = p.fileId
      ? DriveApp.getFileById(p.fileId)
      : DriveApp.createFile(blob);
    if (p.fileId) {
      file.setName(p.filename);
      file.setContent(blob);
    }
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    DriveApp.getFolderById(folderId_()).addFile(file);

    return jsonOut(200, {
      ok: true,
      fileId: file.getId(),
      url: canonicalUrl_(file.getId()),
      name: file.getName()
    });
  } catch (err) {
    return jsonOut(500, { ok: false, message: String(err && err.message || err) });
  }
}
```

```js
export const MAX_IMAGE_BYTES = 5 * 1024 * 1024;

const DATA_URL = /^data:(image\/[a-z0-9.+-]+);base64,([\s\S]+)$/i;

export function decodeDataUrl(dataUrl) {
  const m = DATA_URL.exec(String(dataUrl || ''));
  if (!m) throw new Error('foto harus berupa data URL image/*;base64');
  const mimeType = m[1].toLowerCase();
  const buffer = Buffer.from(m[2], 'base64');
  if (!buffer.length) throw new Error('base64 kosong');
  if (buffer.length > MAX_IMAGE_BYTES) throw new Error('ukuran foto melebihi 5 MB');
  return { buffer, mimeType };
}

export function fileIdFromDriveUrl(url) {
  const m = /\/file\/d\/([-\w]+)/.exec(String(url || ''));
  return m ? m[1] : null;
}
```

```js
import { fileIdFromDriveUrl } from './media-payload.js';

const TIMEOUT_MS = 45_000;

function gasUrl_() {
  const url = process.env.GAS_WEBAPP_URL;
  if (!url) throw new Error('GAS_WEBAPP_URL belum diset');
  return url;
}

async function callGas_(path, init = {}) {
  const ctrl = new AbortController();
  const tid = setTimeout(() => ctrl.abort(), TIMEOUT_MS);
  try {
    const res = await fetch(gasUrl_() + path, { ...init, signal: ctrl.signal });
    const json = await res.json().catch(() => ({}));
    if (!res.ok || !json.ok) {
      throw new Error(json.message || `Apps Script HTTP ${res.status}`);
    }
    return json;
  } finally {
    clearTimeout(tid);
  }
}

export function gasHealth() {
  return callGas_('/?action=health');
}

export async function gasUpsert({ filename, mimeType, dataBase64, fileId }) {
  const out = await callGas_('', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ action: 'mediaUpsert', filename, mimeType, dataBase64, fileId: fileId || null }),
  });
  if (!out.fileId || !out.url) throw new Error('Apps Script tidak mengembalikan fileId');
  return { fileId: out.fileId, url: out.url };
}

export function existingFileId(previousUrl) {
  return fileIdFromDriveUrl(previousUrl);
}
```

```js
import { query } from './db.js';

export const MEDIA_ROLES = new Set([
  'ADMIN',
  'SUPERADMIN',
  'KEPALA',
  'SEKRETARIS',
  'KABID',
  'IRBAN',
]);

export function parseToken(token) {
  if (typeof token !== 'string') return null;
  const parts = token.split('_');
  if (parts.length < 3 || parts[0] !== 'usr') return null;
  const id = Number(parts[1]);
  return Number.isSafeInteger(id) && id > 0 ? id : null;
}

export function bearerToken(req) {
  const raw = String(req.headers?.authorization || '').trim();
  if (!raw) return null;
  const m = /^Bearer\s+(.+)$/i.exec(raw);
  return m ? m[1].trim() : raw;
}

async function defaultLookup(userId) {
  const { rows } = await query(
    'SELECT id, role, instansi_id FROM user_list WHERE id = $1 LIMIT 1',
    [userId]
  );
  return rows[0] || null;
}

export function requireRole(roles, deps = {}) {
  const lookup = deps.lookup || defaultLookup;
  return async function authMiddleware(req, res, next) {
    const userId = parseToken(bearerToken(req));
    if (!userId) {
      return res.status(401).json({ ok: false, message: 'Unauthorized: token tidak ditemukan' });
    }
    let user;
    try {
      user = await lookup(userId);
    } catch (e) {
      return res.status(500).json({ ok: false, message: 'Gagal memverifikasi sesi' });
    }
    if (!user) {
      return res.status(401).json({ ok: false, message: 'Unauthorized: user tidak dikenal' });
    }
    const role = String(user.role || '').toUpperCase();
    if (!roles.has(role)) {
      return res.status(403).json({ ok: false, message: 'Forbidden: role tidak diizinkan' });
    }
    req.user = { id: user.id, role, instansi_id: user.instansi_id };
    next();
  };
}

export function sameInstansi(user, targetInstansiId) {
  if (user.role === 'SUPERADMIN') return true;
  if (targetInstansiId === null || targetInstansiId === undefined) return true;
  return String(user.instansi_id) === String(targetInstansiId);
}
```

```js
INSERT INTO "tanda_tangan" ("nip", "signature", "saved_at", "saved_by")

RETURNING nip`;

  const gasUpsert = deps.gasUpsert;
```

```js
/**
 * Transport ke backend media (Express), terpisah dari apiFetch yang
 * hanya mencoba SERVER_1/SERVER_2 (keduanya n8n).
 * Jangan dipanggil sebelum mediaEnabled() true.
 * SERVER_MEDIA kosong = same-origin.
 * @param {string} endpoint
 * @param {Object} body
 * @returns {Promise<{ok: boolean, data: any, status: number}>}
 */
async function mediaPost(endpoint, body) {
  try {
    const hdrs = { 'Content-Type': 'application/json' };
    if (window._session?.token) hdrs.Authorization = 'Bearer ' + window._session.token;
    const res = await fetch(SERVER_MEDIA + endpoint, {
      method: 'POST',
      headers: hdrs,
      body: JSON.stringify(body),
    });
    const data = await res.json().catch(() => null);
    return { ok: res.ok, data, status: res.status };
  } catch (e) {
    console.error(`[mediaPost] ${endpoint}:`, e.message);
    return { ok: false, data: null, status: 0 };
  }
}

/**
 * GET ke backend media dengan query params opsional.
 * @param {string} endpoint
 * @param {Object} [params={}]
 * @returns {Promise<{ok: boolean, rows: any[], data: any, status: number}>}
 */
async function mediaGet(endpoint, params = {}) {
  try {
    let path = endpoint;
    const qs = Object.entries(params)
      .filter(([, v]) => v !== null && v !== undefined && v !== '')
      .map(([k, v]) => `${encodeURIComponent(k)}=${encodeURIComponent(v)}`)
      .join('&');
    if (qs) path += (path.includes('?') ? '&' : '?') + qs;

    const hdrs = {};
    if (window._session?.token) hdrs.Authorization = 'Bearer ' + window._session.token;
    const res = await fetch(SERVER_MEDIA + path, { headers: hdrs });
    let data = null;
    let rows = [];
    if (res.ok) {
      data = await res.json().catch(() => null);
      rows = Array.isArray(data?.rows) ? data.rows : (data ? [data] : []);
    }
    return { ok: res.ok, rows, data, status: res.status };
  } catch (e) {
    console.error(`[mediaGet] ${endpoint}:`, e.message);
    return { ok: false, rows: [], data: null, status: 0 };
  }
}
```

```js
import { writeFile } from 'node:fs/promises';
import { decodeDataUrl, fileIdFromDriveUrl } from '../server/media-payload.js';
import { gasUpsert } from '../server/gas.js';
import { query, closePool } from '../server/db.js';

const isDataUrl = v => typeof v === 'string' && v.startsWith('data:');

/**
 * Menjalankan migrasi untuk `rows` memakai fungsi `upload` yang di-inject,
 * sehingga bisa diuji tanpa menyentuh Drive.
 *
 * Status 'planned' berarti stub dry-run yang dipakai — tidak ada file dibuat.
 * Status 'uploaded' berarti gasUpsert benar-benar menulis ke Drive.
 * @param {Array<{id: string|number, value: string, kind: string}>} rows
 * @param {(payload: Object) => Promise<{fileId: string|null, url: string|null, planned?: boolean, bytes?: number}>} upload
 * @returns {Promise<Array<{id: string|number, status: string, url?: string, bytes: number, error?: string}>>}
 */
export async function planMigration(rows, upload) {
  const out = [];
  for (const row of rows) {
    if (!isDataUrl(row.value)) continue;
    try {
      const decoded = decodeDataUrl(row.value);
      const uploaded = await upload({
        id: row.id,
        filename: `${row.kind}-${row.id}.png`,
        mimeType: decoded.mimeType,
        dataBase64: decoded.buffer.toString('base64'),
        fileId: fileIdFromDriveUrl(row.value),
      });
      out.push({
        id: row.id,
        status: uploaded.planned ? 'planned' : 'uploaded',
        url: uploaded.url,
        bytes: decoded.buffer.length,
      });
    } catch (e) {
      out.push({ id: row.id, status: 'failed', error: e.message });
    }
  }
  return out;
}

const FACE_SQL = 'SELECT id::text AS id, face_photo AS value FROM user_list WHERE face_photo LIKE $1 ORDER BY id';
const SIGNATURE_SQL = 'SELECT nip AS id, signature AS value FROM tanda_tangan WHERE signature LIKE $1 ORDER BY nip';

async function main() {
  const argv = process.argv.slice(2);
  const apply = argv.includes('--apply');
  const kindArg = argv.find(a => a.startsWith('--kind='));
  const limitArg = argv.find(a => a.startsWith('--limit='));
  const kind = kindArg ? kindArg.split('=')[1] : 'face';
  const limit = limitArg ? Number(limitArg.split('=')[1]) : 0;

  const sql = kind === 'signature' ? SIGNATURE_SQL : FACE_SQL;
  const { rows } = await query(sql, ['data:%']);
  const limited = limit > 0 ? rows.slice(0, limit) : rows;

  console.log(`${apply ? 'APPLY' : 'DRY-RUN'} — ${kind}: ${limited.length} baris base64`);

  // Dry-run tidak boleh menyentuh Drive sama sekali. Stub di bawah hanya
  // mendekode payload dan melaporkan apa yang AKAN terjadi. Memanggil
  // gasUpsert di sini akan membuat file sungguhan dan mencemari folder
  // produksi sebelum migrasi disetujui.
  const upload = apply
    ? ({ filename, mimeType, dataBase64, fileId }) => gasUpsert({ filename, mimeType, dataBase64, fileId })
    : ({ mimeType, dataBase64 }) => ({
        fileId: null,
        url: null,
        planned: true,
        bytes: Math.floor(dataBase64.length * 3 / 4),
      });

  const report = await planMigration(limited, upload);

  for (const r of report) {
    console.log(`  ${r.id}\t${r.status}\t${r.url || r.error || `${r.bytes} B`}`);
  }

  if (!apply) {
    const dump = limited.map(r => ({ id: r.id, base64: r.value }));
    const out = `media-dump-${kind}.json`;
    await writeFile(out, JSON.stringify(dump, null, 2));
    console.log('\nDry-run selesai. Tidak ada file dibuat, tidak ada baris diubah.');
    console.log(`Dump base64 untuk review: ${out} (${dump.length} baris)`);
    return;
  }

  for (const r of report.filter(x => x.status === 'uploaded')) {
    if (kind === 'signature') {
      await query('UPDATE tanda_tangan SET signature = $1 WHERE nip = $2', [r.url, r.id]);
    } else {
      await query('UPDATE user_list SET face_photo = $1 WHERE id = $2', [r.url, r.id]);
    }
  }
  console.log(`\nSelesai. ${report.filter(x => x.status === 'uploaded').length} baris diperbarui.`);
}

if (process.argv[1] && process.argv[1].endsWith('migrate-media-to-drive.mjs')) {
  main()
    .catch((e) => { console.error(e); process.exitCode = 1; })
    .finally(closePool);
}
```
